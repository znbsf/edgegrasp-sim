## 支撑时间对齐修复

旧评分器在位姿回调到达时立即比较最新输入与当前时钟，并在比较前消费该位姿。
MCAP 中旧评分器的 130 个时间拒绝样本均含负年龄，而非 >200 ms 的过期；
位姿 125 次、接触 38 次、关节 4 次（同一事件可同时涉及多个输入）。
例如接收时间 41.419 s、位姿源时间 41.420 s，年龄 −1 ms。
不同回调看到 /clock 的顺序不同，不能把这个瞬时差解释为连续支撑已经中断，
也不能把未来输入直接当作有效输入。

`PlacementSynchronizer` 对位姿暂存，等待本地时钟追上，并匹配源时间不晚于位姿的
接触和关节样本。未来输入不提前判定，不修改源时间或时钟；仍要求输入年龄
≤200 ms、配对差 ≤50 ms，相邻有效位姿间隔 ≤100 ms。
缺少匹配样本会有界等待并拒绝，源/判定时钟回退锁存失败。
在线客户端和离线分析使用同一个同步器；在线还保留关节接收新鲜度检查。
